# Visual references

Drop the reference images into this folder to keep them alongside the code. They were shared
in chat rather than as files, so they could not be written here automatically — save them
from the conversation and use the filenames below so the notes still line up.

| Suggested filename          | What it is                     | What was taken from it                                                                 |
| --------------------------- | ------------------------------ | -------------------------------------------------------------------------------------- |
| `01-rocket-portfolio.png`   | Pencil-rocket illustrator site | Dusty pink → deep purple night sky. Drove the dark theme and the cloud divider.          |
| `02-canva-clouds.png`       | Watercolor cloud element set   | Layered pastel cloud silhouettes in blue, blush, and peach.                              |
| `03-be-kids.png`            | Daycare site, sage and cream    | Organic wave dividers, cream ground, elegant serif headings over soft sans.              |
| `04-kaira-resume.png`       | Warm cream resume layout        | Letter-spaced monospace meta text against a warm cream background.                       |
| `05-cisem-resume.png`       | Grid-paper resume               | Uppercase, widely tracked labels as structural detail.                                   |
| `06-bookavy-dashboard.png`  | Book app, peach → lavender      | Glassmorphic cards, blurred ambient orbs. The single biggest influence on the palette.   |
| `07-smartech-dashboard.png` | Mauve student dashboard         | Circular stat rings, date-chip schedule rows, image-topped project cards.                |

## How each one shows up in the build

- The **orbs** in `components/background.tsx` come from Bookavy's blurred peach and lavender
  gradient field.
- The **cloud divider** above the footer merges the Canva cloud shapes with be-kids' organic
  wave transitions.
- The **skill rings** and **experience timeline** on the home page are adapted from the
  Smartech dashboard's stat rings and schedule list.
- The **monospace uppercase section labels** come from the two resume layouts.

See [`../DESIGN.md`](../DESIGN.md) for the palette, type scale, and component patterns these
translated into.
